> ### 🍋 [Limoni](https://github.com/thebanri/limoni) — High-Performance, Zero-Allocation TUI Framework for Go
> An ultra-fast, thread-safe modern Terminal UI engine engineered for data-intensive dashboards and devtools.
> * **Zero GC Pressure:** `0 B/op` and `0 allocs/op` on the hot rendering path using a 1D contiguous cell buffer.
> * **Lego-Like Composable API:** Declarative layout architecture (`VStack`, `HStack`, `Border`, `Pad`, `Flex`).
> * **3D & Protocols:** Real-time 3D software rasterizer (OBJ/STL/PLY) with Braille subpixels and Kitty/Sixel image protocols.
> * 🔗 **Docs & Live Demo:** [limoni-docs.vercel.app](https://limoni-docs.vercel.app)

### 🚀 About Me

- 🔭 **Main Focus:** Architecting and maintaining **[Limoni](https://github.com/thebanri/limoni)** and exploring zero-overhead systems programming.
- ⚡ **Engineering Philosophy:** Memory locality, cache friendliness, thread-safety, and minimal runtime allocations.
- 🛠️ **Systems & Hardware:** Tinkering with Linux environments, kernel bootloaders, and custom IoT/embedded prototypes.
- 💬 **Ask me about:** Go runtime performance, terminal protocols (ANSI, Sixel, Kitty), diff algorithms, and container orchestration.
- 🎯 **Current Goals:** Expanding declarative TUI primitives and pushing high-throughput data visualizers to the terminal.
